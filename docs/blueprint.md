# **App Name**: TestBuddy.in

## Core Features:

- User Authentication: Secure user login/sign-up with persistent sessions.
- Exam Tests: Provide a variety of exam tests with round patterns stored in Firestore, supporting SSC, Railways, Banking, and other Indian government exams.
- Typing Tests: Enable typing tests with real-time feedback and scoring.
- Performance Tracking: Track user test results and overall performance, visualizing progress over time. Stored in Firestore
- Mock Test Paper Generation: AI tool that assembles mock test papers using data models of questions with options and correct answers.
- Personalized Exam Recommendations: AI analyzes user performance and recommends specific exam tests and practice areas.
- Firestore Data Storage: Store user data (login, password, ID, test results, exam preparation), exam patterns, and question datasets in Firestore.

## Style Guidelines:

- Primary color: Deep saffron (#FF9933) to evoke the spirit of India and academic rigor.
- Background color: Very light tan (#F5F5DC) to provide a neutral and focused learning environment.
- Accent color: Teal (#008080) to highlight important calls to action and key information.
- Font pairing: 'Space Grotesk' (sans-serif) for headlines and 'Inter' (sans-serif) for body text.
- Use clean, modern icons representing exam categories and features.
- Implement a grid-based layout for a responsive and organized design.
- Use subtle animations to provide feedback and enhance user engagement.
